# NEMOQWEN Content Adaptation

Use this skill when one source asset or release must produce platform-specific packages.

## Source preservation

Treat the creator's supplied title, lyrics, video, artwork, caption, factual claims, and explicit constraints as source material.

Do not silently:
- soften or sanitize meaning;
- invent facts or metrics;
- replace creator voice with generic marketing copy;
- turn one creator type into another;
- modify the master media file unless the requested output requires a derivative.

Create derivatives; preserve masters.

## Adaptation sequence

1. Read creator profile: primary type, secondary types, voice, pillars.
2. Read release manifest and assets.
3. Identify each platform's actual target mode.
4. Produce platform-specific:
   - title;
   - body/caption;
   - tags/hashtags only where useful;
   - CTA;
   - asset selection;
   - aspect/cut recommendation;
   - accessibility text/captions;
   - content warning or disclosure when required.
5. Record which fields are source-derived versus newly generated.
6. Never publish during a content-only task.

## Platform lenses

### Facebook
Favor context, community discussion, native video/carousel use, and readable copy. Do not assume external links or hashtags improve distribution.

### TikTok
Prioritize the opening seconds, vertical framing, readable captions, and a self-contained post. Do not pretend trends or sounds are current without live evidence.

### YouTube
Separate long-form, Shorts, title/description, thumbnail, chapters, playlist, and disclosure metadata. Optimize for durable discovery without clickbait that misrepresents the video.

### Reddit
Adapt to the specific subreddit and post type. Community rules and audience norms outrank generic campaign language. Never manufacture grassroots endorsement.

### X
Use concise, conversational posts, replies, quotes, or threads as appropriate. Preserve context when replying and do not convert every release into a thread.

## Creator-type overlays

Examples:
- musician: song story, release context, hook clip, lyrics fragment, performance clip;
- podcaster: episode thesis, guest clip, quote, segment;
- video creator: hook, short derivative, behind-the-scenes, full release;
- visual artist: process, final artwork, carousel, detail crop;
- educator: concept, example, resource, correction;
- comedian: premise, bit, clip, callback;
- maker/engineer: build result, failure analysis, demo, technical detail;
- brand/nonprofit: campaign objective, evidence, CTA, disclosure.

Mixed creator profiles can combine overlays without forcing one identity.

## Quality gate

Before returning a package, verify:
- meaning preserved;
- creator voice preserved;
- platform format appropriate;
- no invented current trend claims;
- no unsupported performance promises;
- accessibility surface included when relevant;
- publication authority not implied.
